## 🎯 HOW TO USE

### Step 1: Start Your App
```bash
npm run dev
```

### Step 2: Navigate to Login
```
http://localhost:3000/login
```

### Step 3: Access Staff Registration
1. Click "Hospital Staff" tab
2. Click "Register here" link
3. OR Direct: http://localhost:3000/staff-register

### Step 4: Fill Form
```
Full Name: John Doe
Staff ID: EMP2024001
Gender: Male
Contact: 5551234567
Email: john@hospital.com
Address: 123 Main St, City
Username: johndoe123
Designation: Doctor
Password: SecurePass123
Confirm: SecurePass123
```

### Step 5: Submit & Verify
1. Click Register
2. See success message
3. Verify email
4. Login with credentials
